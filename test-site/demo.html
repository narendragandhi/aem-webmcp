Frequently Asked Questions

What is WebMCP? ▼

WebMCP is a W3C standard that lets websites expose structured tools to AI agents. Instead of scraping your DOM, agents call named tools with typed parameters.

How does this demo work? ▼

Every product, form, and component on this page is registered as a WebMCP tool. The AI concierge chatbot calls these tools to help you — no DOM scraping needed.

Can I build my own tools? ▼

Yes! Call AEMWebMCPAutomator.registerTool() with a name, description, schema, and handler function. Any AI agent on the web can discover it.
